# DigitalNest Website Prototype

Website statis berdasarkan dokumen draft alur program dan silabus Digital Marketing.

## Isi
- `index.html`: struktur dan konten website
- `styles.css`: gaya responsif desktop/mobile
- `script.js`: tab kurikulum, navigasi mobile, dan formulir simulasi
- `assets/digitalnest-logo.jpg`: logo yang diberikan

## Publikasikan ke GitHub Pages
1. Buat repository publik, misalnya `digitalnest`.
2. Upload seluruh isi folder ini ke root repository, termasuk folder `assets`.
3. Pilih **Settings → Pages**.
4. Source: **Deploy from a branch**; Branch: **main**; Folder: **/(root)**; klik **Save**.
5. Tunggu deploy, lalu buka URL yang ditampilkan GitHub Pages.

Formulir hanya simulasi browser dan tidak mengirim/menyimpan data. Detail harga, sertifikasi, mitra, ISA, dan penempatan kerja perlu dikonfirmasi penyelenggara sebelum website digunakan secara publik.
